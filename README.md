# Personal Portfolio Website

## 📌 Project Overview

This is a responsive personal portfolio website created using **HTML and CSS**. It showcases my profile, skills, projects, and contact information in a simple and professional design.

The website includes separate pages for each project and uses responsive layouts so that the content can adapt to different screen sizes.

## 🚀 Features

* Home section with personal introduction
* About Me section with profile image
* Skills section
* Projects section with three projects
* Individual project detail pages
* Contact form
* Fixed navigation bar
* Smooth scrolling navigation
* Responsive design
* Hover effects and animations
* Social media icons using Font Awesome
* Responsive project grid using CSS Grid
* Flexbox-based layouts

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
* Font Awesome
* Responsive Web Design

## 📱 Responsive Design

The website includes a CSS media query for smaller screens.

On mobile devices:

* The About section changes to a vertical layout.
* Project cards are displayed in a single column.
* Content adjusts to fit smaller screen sizes.

## ▶️ How to Run

1. Download or clone this project.
2. Keep all HTML, CSS, and image files in the same folder.
3. Open the project folder in **VS Code**.
4. Open `index.html` in a browser.

You can also use the **Live Server** extension in VS Code to run the website.

## 🔗 Project Navigation
